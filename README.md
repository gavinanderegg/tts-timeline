# The Talk Show Timeline

I charted the release days of [John Gruber's The Talk Show](https://daringfireball.net/thetalkshow/) to satisfy my curiosity about how a recent gap in the schedule lines up with the previous release schedule. Turns out not to have been a big deal, but I thought I'd share it anyway. I wrote up some thoughts and findings on my blog here: [https://anderegg.ca/2026/09/08/the-talk-show-timeline](https://anderegg.ca/2026/09/08/the-talk-show-timeline).
